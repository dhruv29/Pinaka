What AI are you actually running?

Pinaka reads a repository or a live Kubernetes cluster and writes down every model, AI library, hosted provider, model server and agent tool it finds, with the file or workload it was seen in and the handful that deserve a look first. 

pinaka scan -repo . -kube -format json -out ai-bom.json

      How it runs

      1. Nothing goes inside your containers

        Pinaka is one small program. Run it on a laptop, in a pipeline, or as a nightly job.

      2. It only reads

        A repository scan opens files and makes no network calls. A cluster scan uses only kubectl get and never asks for secrets.

      3. Credentials by name, never value

        It tells you that OPENAI_API_KEY is written into a workload in plain text. It does not copy the key.

      4. Output other systems can use

        A report for people, Pinaka's own JSON, or a CycloneDX 1.6 document for inventory and compliance tools.
